백엔드 : 	눈에 보이지 않는 모든 '기능과 처리' (계정 정보, 로그인, 랭킹, 유저 데이터 저장....)
	사용자가 무언가 행동했을때, 보이지 않는 곳에서 데이터를  처리하고, 저장하고, 처리한 데이터를 다시 프론테엔드에 보내주는 역할

프론트엔드 : 사용자가 직접 보고 조작하는 부분
	    버튼, 텍스트박스, 이미지, 메뉴 등 사용자가 직접 눈으로 보고, 클릭하거나 입력하는 화면을 구성하고 동작하게 만드는 부분

클라이언트 : 서버와 통신하여 서비스를 요청하고 응답을 받는 '네트워크 구조상의 주체'
	    즉 플레이어의 기기에서 실행되는 게임 프로그램

클라이언트 != 프론트엔드 : 	두 용어는 상당히 비슷해 보이지만 좁은 범위에서는 같은 말이 아니다.
			프론트엔드는 웹 개발에서 많이 사용되는 용어,
			클라이언트는 게임이나 네트워크 프로그램에서 많이 사용되는 용어
